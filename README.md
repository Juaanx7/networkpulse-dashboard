# NetworkPulse Dashboard

Modern **Network Monitoring Dashboard** built with **React + Vite**.  
NetworkPulse simulates an ISP admin panel where operators can monitor clients, traffic and network performance in real time.

This project was created as part of my **Frontend / Full Stack developer portfolio** to showcase dashboard UI development, data visualization and responsive admin layouts.

## Features

### Dashboard
- Network metrics overview
- Traffic analytics chart
- Network nodes status
- Device distribution visualization
- Connected clients table

### Clients Management
- Clients table with status indicators
- Real-time search filtering
- Plan filtering
- Status filtering
- Network summary cards

### UI / UX
- Responsive admin layout
- Mobile sidebar with hamburger menu
- Horizontal card carousel on mobile
- Clean SaaS-style interface
- Smooth hover and transition effects
